What it does

A terminal first, and honest about it.

Rendering

Drawn on the GPU

Grid, chrome and tab strip are one GPUI scene. Emulation runs on its own thread, so a program flooding stdout never stalls the window.

Layout

Panes that stay flat

Split right or down to any depth. Splitting along an axis a pane already occupies adds a sibling instead of nesting, so the tree is still readable after the tenth split.

Context

Opens where you are

A new tab or split starts in the current pane's working directory, read from the pty's foreground process group — not wherever the app happened to launch.

Coding CLIs

shift enter is a newline

Terminals have always sent one byte for both. botttle sends ESC CR, the sequence Claude Code's own setup installs elsewhere, so a prompt takes another line instead of sending.

Coding CLIs

Paste an image

ctrl v writes a clipboard image to a file and types the path — how Claude Code and Codex take images. With no image, the keystroke reaches the program untouched.

Navigation

⌘ click opens it

Hold ⌘ and the URL or path under the pointer underlines. Paths resolve against the pane's directory and a file.rs:42:9 suffix opens the file. A path has to exist before it counts.

Keys

⌘ on macOS, ctrl+shift elsewhere.

⌘TNew tab
⌘D ⌘⇧DSplit right, split down
⌘] ⌘[Focus the next or previous pane
⌘⇧] ⌘⇧[Next or previous tab
⌘W ⌘⇧WClose the pane, close the tab
⌘C ⌘VCopy the selection, paste — an image if the clipboard holds one
⌘= ⌘- ⌘0Font size, and back to default
⌘,Settings — theme, fonts, cursor, scrollback

Everything else reaches the program untouched. ctrl-c, ctrl-d, ctrl-z and the rest belong to the shell, not the terminal.

Install

A recent stable Rust toolchain is all it takes.

macOS

Builds a release app, gives it the icon, signs it with the best identity in your keychain, and puts it in /Applications.

git clone https://github.com/launchdoor-studio/botttle
cd botttle && scripts/bundle-macos.sh --install

From source

Runs anywhere GPUI does. On Linux you will also want the usual Wayland or X11 development packages.

cargo run --release
cargo test
